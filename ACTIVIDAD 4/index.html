/* esta es una explicacion de como funciona un documento html, en primer lugar la etiqueta !DOCTYPE html indica que el documento es de tipo HTML5. Luego, la etiqueta html define el inicio del documento HTML y el atributo lang="es" especifica que el idioma principal del contenido es español. Dentro de la etiqueta head, se encuentran metadatos importantes como la codificación de caracteres meta charset="UTF-8" y la configuración de la vista para dispositivos móviles meta name="viewport" content="width=device-width, initial-scale=1.0". La etiqueta title establece el título de la página que se muestra en la pestaña del navegador. El contenido visible de la página se encuentra dentro de la etiqueta body. Aquí se incluyen tres secciones principales: header, main y footer. La sección header contiene un título o encabezado para la página, en este caso "Sisifo Gym". La sección main alberga el contenido principal, que es un mensaje de bienvenida. Finalmente, la sección footer proporciona información adicional, como derechos de autor. Es importante que el documento se llame index.html, ya que esto permite que los navegadores web lo reconozcan como la página principal del sitio web. */
